# 🔳 QR Code Generator

A simple and interactive **QR Code Generator** built with **HTML, CSS, and JavaScript**. This web application allows users to generate QR codes instantly for any text, URL, or data with a clean and responsive interface.

---

## 🚀 Features

- 🔗 Generate QR codes for URLs, text, or other data  
- 🌐 Fully responsive design for mobile, tablet, and desktop  
- 🎨 Clean and user-friendly interface with CSS styling  
- ⚡ Instant generation with JavaScript  

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript  
- **No Backend Required** – Fully client-side  
- **Version Control**: Git & GitHub
